# 🛡️ 안전카드뉴스 비디오 스튜디오 V2 (Safety Card Video Studio)

> **이미지(PNG/JPG)와 동영상 클립(MP4/WebM)을 자유롭게 교차 삽입하여 AI 음성(TTS), 자막, 배경음악이 결합된 고화질 MP4 동영상을 자동 제작하는 하이브리드 웹 스튜디오**  
> 100% 브라우저 클라이언트 사이드 기반으로 동작하여 **서버 설치 없이 바로 실행** 가능하며, **GitHub Pages**를 통해 사내 임직원 누구나 웹 링크로 접속해 활용할 수 있습니다.

---

## ✨ V2 신규 및 핵심 기능

1. **🎬 이미지 & 동영상 하이브리드 카드뉴스**
   - 이미지(PNG, JPG, WebP) 및 **현장 작업 동영상 클립(MP4, WebM, MOV)** 동시 지원
   - 슬라이드 목록에 `[🖼️ 이미지]` / `[🎬 비디오]` 뱃지 자동 구분
   - 비디오 카드별 실시간 썸네일 생성 및 미리보기 지원

2. **🎛️ 동영상 카드 전용 커스텀 옵션**
   - **레이아웃 연출**: 풀스크린(Full) 화면 채우기 vs 카드 템플릿 프레임 속 액자형(PiP) 선택
   - **사운드 제어**: 영상 원본 소리 음소거(Mute) 또는 AI 성우 나레이션과의 볼륨 믹싱
   - **길이 자동 동기화**: 대본 길이에 따른 비디오 루프 및 싱크 맞춤

3. **🎙️ 고품질 한국어 AI 음성 (TTS)**
   - 브라우저 내장 신경망 음성 지원 (차분한 안내 톤, 신뢰감 있는 남성/여성 성우)
   - 나레이션 속도(0.7x ~ 1.4x) 및 카드 간 여유 간격(Pause) 정밀 제어
   - 카드별 즉시 음성 미리듣기(Preview) 지원

4. **📝 자막 & 배경음악(BGM) 스타일링**
   - 가독성 높은 한국어 자막 자동 래핑 및 오버레이 (하단 바, 플로팅 캡슐, 텍스트 섀도우 등)
   - 차분한 안전 교육용 앰비언트 BGM 내장 및 볼륨 믹싱 (1% ~ 30%)
   - 카드 간 부드러운 전환 효과 (페이드, 슬라이드, 컷)

5. **🎬 고화질 동영상(MP4/WebM) 렌더링 & 다운로드**
   - 1:1 (정사각형/메신저용), 4:5 (모바일 최적화), 16:9 (사이니지/전광판용) 비율 지원
   - 실시간 진행률(Progress Bar) 표시 및 렌더링 완료 즉시 브라우저 재생 및 파일 다운로드

6. **🔒 100% 사내 프라이버시 보호**
   - 모든 이미지, 영상, 대본은 외부 서버로 전송되지 않고 사용자의 웹 브라우저 내에서만 안전하게 처리됩니다.
